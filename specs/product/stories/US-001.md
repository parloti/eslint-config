# User Story: Remove Jasmine and Jest configuration support

- **ID:** US-001
- **Status:** Draft — implementation in progress
- **Approval State:** Not requested

## Business Framing

- User / Stakeholder: Consumers of the shareable ESLint config
- Problem: Jasmine and Jest integrations are part of the package's public surface even though they are being retired.
- Outcome: Consumers receive a smaller, explicit set of supported test-framework integrations.

## Story

As an ESLint config consumer, I want Jasmine and Jest support removed, so that the package exposes only the integrations it continues to support.

## Minimal MVP Slice

Remove Jasmine and Jest modules from the public types, loader registry, exports, dependencies, tests, and consumer documentation.

## Delivery Artifacts

- Requirements: [Use case](../../use-cases/removing-jasmine-and-jest.use-case.md)

## Business Acceptance Criteria

- Jasmine and Jest cannot be selected through the typed plugin options or scoped plugin list.
- The package no longer exports or loads Jasmine or Jest config modules and no longer declares their plugin dependencies.
- Consumer documentation lists only currently supported testing modules.
